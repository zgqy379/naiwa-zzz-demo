## 1. UI 视觉语言

### 1.1 色彩体系

【转述·知乎前端复刻实战】绝区零的配色可归纳为「一主二辅」：

| 角色 | 颜色 | 近似色值 | 用途 |
| --- | --- | --- | --- |
| 主撞色 | 高饱和亮黄 × 纯黑 | `#FFD93D` × `#0A0A0A` | 主按钮、高亮态、标题、强调 |
| 辅色 1 | 霓虹青 | `#00F0FF` | 冷色调点缀、次级信息、描边光 |
| 辅色 2 | 霓虹品红 | `#FF2D95` | 热色调点缀、危险/暴击氛围 |
| 中性 | 近黑灰阶 | `#1A1A1A` / `#2A2A2A` / `#F5F5F5` | 面板底、正文 |

要点：
- **黄黑是身份色**，青/品红只做小面积点缀，避免整屏霓虹；撞色出现在「交互高亮」上，而非铺底。【转述】
- 战斗内敌人侧用红系警示（支援点不足/不可格挡为红光），玩家侧用金系（可极限支援为金光）。【实测类信源·机核】
- 【转述·观察者网视觉辞典】角色、UI、特效常用互补色/分裂补色对比，但「色块体积普遍不大，倾向让色彩融入整体环境」；六分街场景被刻意压低明度与纯度形成「高级灰」，让 UI 的黄黑在低饱和场景中跳出来。**这条对我们最重要：场景降饱和、UI 高饱和，二者互为衬托。**

### 1.2 形状语言

【转述·知乎复刻实战】ZZZ 的按钮、卡片、面板几乎找不到正圆角，全是**斜切角与倾斜平行四边形**，传达「速度感 + 工业感」：
- 切角大小约 6–16px（复刻者取 12px 面板 / 16px 按钮 / 6px 小开关）；
- 面板常用「右上+左下对角切角」或「四角不等切」，按钮更夸张；
- 排版大量用 `-6deg` 级别的倾斜容器与错位排版，标题、贴纸、评价章都带旋转角；
- 斜切角配 `clip-path` 实现（切角处无边框，需要描边时用双层元素模拟）。

### 1.3 字体

【转述·机核《绝区零》UI 字体速评 + 知乎美术驱动解析 + kdxiaoyi 博客】
- ZZZ 用的是**印品鸿蒙体**（Bold + 疑似米哈游定制的 Thin 细体），并以**可变字体（VF）**技术接入，设计师可调字重/中宫/字怀/字面，「排版非常炫技」——这是少有在游戏里用 VF 的作品。
- 风格定位：**超粗黑体 + 黑底白字 + 大字距**，标题偶尔加描边或阴影；正文用同族紧凑无衬线。
- **机核的专业批评（反面教材，我们要避开）**：
  - 超粗字体的负空间被挤压，缩到正文字号会「糊成一团」；黑底白字因白色自发光视错觉更粗，负空间进一步被吞；
  - 正确做法：**深浅主题分别配字重**（深底用更细字重补偿视错觉），标题字与正文字分开选；
  - 字形细节（「法」「与」「新」的笔画处理）在整段文字中会累积成粗糙观感——「计白当黑」是底线。
- 游戏内置「字体粗细」设置（推荐/全细/全粗），说明米哈游自己也收到了可读性反馈。

对我们可用的等效选择：标题可用思源黑体 Heavy / 站酷庆科黄油体级数的超粗几何黑体（我们已登记 OFL 的两个站酷字体即属此气质），正文必须换可读性优先的黑体（Noto Sans SC / 思源黑体 Regular），并遵守「深色底配细字重」。

### 1.4 漫画语言（美漫 DNA）

【转述·观察者网视觉辞典】这是 ZZZ 区别于一般二游的核心：
- **冲击帧（impact frame）**：宣传片与实战频繁出现，「往往结合故障艺术、反色效果、美式漫画中的本戴点（Ben-Day dots）与拟声词」；
- **科比斑点（Kirby Krackle）**：虫洞内黑色圆点，源自美式漫画；
- **网点纸（halftone）/本戴点**：作为高光、阴影与速度区域的纹理语言；
- **拟声词**：战斗音效字（BAM/KABOOM 类）直接作为画面元素；
- 贴纸感、巨大招牌、街头涂鸦、录像带封面构成平面设计空间；
- TapTap GAF 艺术节总结：**「街头涂鸦的随性 + 复古录像带噪点质感 + 热血角色张力」**。

### 1.5 与「液态玻璃」质感的关系

ZZZ 的 UI 本体**不是玻璃拟态**——它是「平面海报拼贴 + 工业印刷」逻辑（网点、噪点、描边、斜切），面与面之间靠色彩和描边分层，而非 blur 透镜。我们的液态玻璃是自家资产，不必推翻，但要注意：
- 玻璃适合放在「背景承载层」（面板底、卡片），**漫画元素（斜切、描边、网点、拟声词）放在玻璃之上的前景层**，二者不打架：玻璃管「透与厚」，漫画管「形与噪」；
- 玻璃面板上叠超粗字时，遵循 1.3 的字重补偿原则（我们已有深浅主题变量，正好对上）；
- 玻璃的高光描边环与 ZZZ 的「1.3px 渐变描边 + 亮边」气质接近，可以保留，但把圆角收敛成小圆角/斜切，避免「iOS 味」盖过「漫画味」。

### 1.6 反面教材（UI 可读性批评，改造时对照规避）

【转述·知乎锐评两篇】
- 字体颜色混乱、**滥用椭圆底衬**导致信息可读性差；
- 深色模式下配色对比不足、图标指代模糊；
- 机核补充：无意义光效闪烁、按钮随音乐跳动、角色详情页流程混乱。
→ 对我们的启示：撞色只给「当前可交互/关键状态」用；一个信息一个底衬形状；HUD 常驻元素不做常亮闪烁（只在状态切换时闪一次）。

## 2. 战斗 HUD 布局

综合【实测类信源：机核战斗拆解、gamekee、蓝叠 wiki、17173、Prydwen】：

| 元素 | 位置 | 形态与颜色 | 备注 |
| --- | --- | --- | --- |
| 我方角色状态 ×3 | **左上角** | 竖排三个头像块，绿色长条血量；血条下方**发光格子**为能量值（最多 2 格，发动强化特殊技），能量不足灰、足够变彩色 | 切人候选头像就在这里，连携时也按左/右头像选人 |
| 喧响值（Decibel） | **屏幕左侧**（贴边竖向） | 全队共享，上限 3000，三级进度；满 3000 可放当前角色终结技；形态为带四角星的能量槽，分段显示 | 攻击/闪避/连携/支援追击都累积，**不下降**（用满清零） |
| 敌人血量 | 敌人头顶（精英/首领的详细血量在**右上角**常驻） | 绿色，受击时显示**虚血（白色滞后条）**表示刚扣的量 | 虚血是打击反馈的重要一环 |
| 失衡条（Daze） | 敌人血条下方 | **黄色进度条 + 黄色百分比数字**；满 100% 敌人失衡：条**变彩色**并闪烁显示失衡易伤倍率（默认易伤 +50%）；失衡值达上限后转灰随时间衰减 | 7 种状态机（17173 详解） |
| 属性异常积累槽 | 敌人血条/失衡条旁 | 独立小槽，触发异常后清零 | 我们暂无异常系统，可映射为「克制环」可视化 |
| 支援点（Assist Points） | 换人按钮区域（头像附近） | 敌人**可弹反攻击出金光**提示（此时切人=极限支援）；红光=不可格挡；上限 3 点，连携技回补 | 无支援点时切人会自动完美闪避兜底 |
| 连携技 QTE | **屏幕下方** | 失衡敌人被重击命中 → 约 **3 秒子弹时间** + 底部出现左右角色**头像框 + 倒计时**，按左/右选人释放 | 头像框即 QTE 按钮本体 |
| 连击数（Combo） | 屏幕侧边（右上区域） | 大号数字 + 连击字样，命中刷新 | 搜索未见精确版式描述，以截图口径「屏幕侧边大数字」为准 |
| 目标追踪 | 敌人身上/头顶 | 小黄点 → 圆靶图标切换 | 引导焦点 |
| 终结技按钮 | 技能区（右下） | 喧响值满时点亮（发光） | 消耗全部喧响值 |

**布局逻辑总结**：玩家状态集中左上、敌人状态跟敌走 + 首领右上冗余、资源条（喧响）左缘竖排、操作/QTE 区在下缘。**所有条都是「胶囊/斜切条 + 高饱和色 + 黑描边」**，与我们现有 HUD 胶囊兼容。

## 3. 关键演出时刻

1. **切换角色 / 极限支援**【转述·观察者网】：敌人攻击瞬间切人触发——屏幕闪过**十字型金色闪光**，支援角色以**金色描边 + 闪光高速登场**，镜头快速拉近、由虚转实，承受冲击后退步；伴随「叮」提示音与**时停感**。【实测类信源】金光=可弹反，红光=不可格挡。
2. **连携技 QTE**【转述·观察者网 + 机核】：重击命中失衡敌人 → 约 3 秒**子弹时间慢放**，镜头快速拉近；屏幕快速闪过**「从红蓝转为半透明的冲击帧提示」**；底部左右头像 + 倒计时选人；首领可连打 3 次连携（精英 2、小怪 1）。
3. **终结技**：喧响值满释放 →「极其炫酷的大招演出」，**全屏专属运镜 + 时停感**，演出期间**角色无敌帧**【实测类信源·机核/萌百】——华丽演出不破坏战斗公平的关键设计。
4. **极限闪避 / 完美招架**：极限闪避触发**时停式慢动作**，可接闪避反击（重击效果）；完美支援后按普攻/特殊技接「支援追击」；无支援点时自动完美闪避兜底。【实测类信源·Prydwen/17173】
5. **失衡瞬间**：敌人**无法行动、瘫痪姿态**，失衡条变彩色闪烁 + 易伤倍率展示，此时是连携技窗口；失衡后承伤 +50%。
6. **镜头语言**【转述·观察者网】：摇晃顿挫的「表演感」，快速拉近拉远与环绕，类似 MV 广告节奏；攻击时若敌人不在画面内，相机快速偏转，敌人保持在屏幕约 1/3 边界处。【实测类信源·机核】

## 4. 伤害与打击反馈

- **伤害数字**：命中弹出伤害数字；**暴击数字放大并带 "!!" 标识**，与普通数字明显区分【实测类信源·17173 伤害乘区课】。
- **Hit stop（顿帧/卡肉）**：ZZZ 顿帧极重，几乎每次命中都有帧冻结——社区评价分裂：有人认为「打击感核心」，有人抱怨高攻速下像「卡顿表演」，请求可关【转述·HoYoLab/Steam 讨论】。→ 启示：**顿帧要随攻击强度分级**（轻击短、重击长、终结技最长），且给设置开关。
- **冲击帧（impact frame）**：大招与关键命中插入 1–2 帧的**黑白/反色 + 本戴点 + 拟声词**画面，是「漫画感」最高浓度时刻【转述·观察者网】。
- **镜头与震屏**：摇晃顿挫 + 快速推拉环绕（见 §3.6）；命中伴随屏幕震动。
- **虚血条**：白色滞后条展示「这一下打掉了多少」，延迟收缩——低成本的强反馈手法。
- **音效/提示**：「叮叮叮」支援提示音等强化演出认知【实测类信源·B站新手指南】。

## 6. 场景氛围（六分街）

【转述·界面新闻 + 观察者网 + 官方丽都创作笔记】
- **基调**：80 年代日式复古小街区——老电影、唱片店、录像厅、街机厅（「装潢和日本经典街机厅完全一致」）、形似八代丰田皇冠的汽车；泡泡经济时代文化符号 + 当下潮流糅合（90 年代 / Y2K / 波普）。
- **显像管电视是「视觉系统核心」**：肉鸽棋盘每格都是一台老电视，部分格子出现无信号彩虹条；测试版开始界面即一台显像管电视播放复古短片（电视购物、《星徽骑士》特摄戏仿）。
- **平面设计密度**：「好的都市题材离不开大量的招牌和广告」（官方美术访谈）；巨大招牌、涂鸦海报、录像带封面、黑胶封面戏仿知名专辑；墙面涂鸦 + 涂鸦喷罐街区等级系统（嘻哈文化）。
- **灯光**：场景整体压低明度纯度成「高级灰」，霓虹与招牌局部高饱和点亮；外露功能性结构（音像店门口挂满黑胶、店铺内部细节满当）营造「烟火气」。
- **东西混搭**：西方街头文化 + 东方城镇布局（路边石狮子）。
- **阵营风格区分**：狡兔屋街头、白祇重工粗犷工业、维多利亚家政慵懒优雅——用一套语言的不同子风格区分阵营。
- 已知问题：信息过饱和，长时间游玩易疲乏【转述·界面新闻】→ 我们街景要控制「招牌密度梯度」，焦点区密、背景区疏。

## 7. 《奶蛙零》可落地规范

> 约束前提：我们已有 CSS 液态玻璃（screens.css 全局材质组）、NPR 三渲二、漫画风 HUD、4 屏流程与 E2E 25 条断言（改 HUD 不得破坏选择器与 stats 结构）；三连战 / 招式克制（×1.25/×0.85）/ 蓄力必杀 / 弹反（counter.mjs）已上线。改动一律遵守 AGENTS.md 登记制，只动 `src/ui/`、`src/game/tuning.mjs`（展示线白名单）。

### 7.1 HUD 胶囊：斜切与描边规范

- **形状**：现有胶囊保留玻璃底，外层加 1.3px 渐变描边环（已有）；新增 `clip-path` 斜切角变体用于「强调级」元素（连击数、QTE 头像框、评级章）：

```css
/* 强调级：右上+左下切角，玻璃面板仍可内衬 */
.zzz-cut {
  clip-path: polygon(12px 0, 100% 0, 100% calc(100% - 12px),
                     calc(100% - 12px) 100%, 0 100%, 0 12px);
}
/* 倾斜容器：标题/连击数用 */
.zzz-skew { transform: skewX(-6deg); }
.zzz-skew > * { transform: skewX(6deg); } /* 内容回正 */
```

- **色彩令牌**（CSS 变量，全部只用于强调态与前景层，不铺底）：

```css
:root {
  --zzz-yellow: #FFD93D;   /* 主强调：连击/QTE/评级S */
  --zzz-black:  #0A0A0A;   /* 黄底上的字 */
  --neon-cyan:  #00F0FF;   /* 冷点缀：能量/喧响 */
  --neon-magenta: #FF2D95; /* 热点缀：暴击/失衡满 */
  --enemy-red:  #FF3B3B;   /* 不可格挡警示 */
}
```

- **血条虚血**：血条加一条白色滞后层（宽度用 CSS transition 延迟收缩 300ms），零 WebGL 成本，纯 DOM。
- **字重分级**：深色底（战斗 HUD）用 600–700 字重；黄底强调块用 900 黑字；正文（设置/说明）禁用 900。

### 7.2 连携 QTE：DOM + CSS 实现方案

现有三连战 + Tab 接力已有「切人」逻辑，可加演出壳：
