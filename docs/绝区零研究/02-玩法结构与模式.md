## 1. 核心玩法循环：一场战斗的完整结构

### 1.1 单场战斗的微观循环（实时动作层）

绝区零的战斗是 3 人小队实时动作战斗，微观循环是全游戏所有模式的共同内核：

```
常态阶段（攒条期）
  ├─ 普攻/连段、冲刺、特殊技、强化特殊技（消耗能量）
  ├─ 每次「切换代理人」（Swap）触发 支援技/快速支援（Quick Assist）
  ├─ 敌人攻击瞬间的 切换/闪避 → 招架支援（Defensive Assist）
  │    └─ 完美招架（Perfect Assist）＝零成本招架 + 大量失衡值
  └─ 目标①：把敌人 失衡条/Daze 条 打到 100%（黄色 → 临界 → 彩虹色）
        ↓
失衡阶段（爆发期）
  ├─ 敌人眩晕（Stunned）：无法行动、承受易伤增伤
  ├─ 对眩晕敌人使出 重击/强化特殊技 → 触发 连携技（Chain Attack）
  │    └─ 需 2 人以上小队；一次失衡窗口可触发多次连携（见 §3.2 分档）
  ├─ 连携技/终结技命中 → 回复 支援点数（Assist Points），反哺下一轮切换
  └─ 目标②：在失衡窗口内打出全队最高伤害
        ↓
循环重启：失衡条清空，进入下一轮「攒条 → 失衡 → 爆发」
```

**关键设计判断：失衡 → 连携技是整个战斗循环的枢纽。**
- 它把「打输出」变成「打节奏」：常态阶段的每一招都有两个价值——直接伤害 + 失衡值（Daze，即传统 ACT 的削韧/韧性条），不同招式有不同「失衡倍率」（压制力），玩家要为攒条牺牲一部分直接伤害。
- 它让「切人」从操作花活变成资源循环：连携技回复支援点数 → 支援点数支持下一轮招架/快速支援 → 招架攒失衡 → 再进失衡窗口。输出、生存、切人三件事被同一个窗口串起来。
- 它是难度与爽感的分频器：小怪失衡快、Boss 失衡慢但窗口大，同一套机制覆盖所有敌人档位（见 §3.2）。

### 1.2 单场关卡的宏观结构（进战 → 波次 → Boss → 结算）

主线战斗委托（Combat Commission）的典型结构：

| 环节 | 内容 | 时长量级 |
| --- | --- | --- |
| 进战 | 波次通告、开场演出（可跳过）、敌人分批刷新 | <10 s |
| 波次 | 通常 **1–3 波**：小怪波 → 混合波 → 精英/Boss 收尾 | 各 20–60 s |
| Boss | 精英或 Boss 压轴，多阶段（见 §3.3） | 60–120 s |
| 结算 | 评级 C/B/A/S + 统计面板（见 §5） | <10 s |

**单场战斗时长量级：约 1–3 分钟。** 练度碾压时 1 分钟内；S 评级通常要求限时通关，主线常见硬性条件是 **120 秒内通关给 S**。一整段主线委托（含走格子/剧情）约 10–20 分钟，纯战斗段即 1–3 分钟。

### 1.3 中观循环（局与局之间）

```
主线推进（战斗委托 + 叙事）
  → 常驻刷取层：驱动盘本（定期清缴 Routine Cleanup）/ 音擎材料 / 经验本（战斗模拟 Combat Simulation）
  → 周常挑战层：恶名狩猎（周本 Boss）+ 危局强袭战（Deadly Assault）
  → 版本挑战层：式舆防卫战（双周刷新）+ 零号空洞（肉鸽）
  → 结算产出养成资源 → 练度提升 → 打更高的挑战层（§2 全部模式的入场逻辑）
```

## 2. 主要模式盘点与结构

### 2.1 剧情战斗（Phaethon's Story / 主线）

- 混合结构：早期（1.0–1.3）= HDD 走格子（TV 模式）+ 战斗委托交替；1.4 起主线基本纯叙事 + 战斗。
- 战斗委托结构同 §1.2：1–3 波 + 限时 S 评级。
- 部分委托有特殊规则：双人上场、禁切换、保护目标等，用于教学与演出。

### 2.2 零号空洞（Hollow Zero）——肉鸽模式

常驻高随机肉鸽探索模式，入口在斯科特哨站，完成主线「资质考核」解锁。子模式包括：枯败花圃（Withered Domain）、迷失之地（Lost Void）、琶音断层（Arpeggio Fault）等。

**结构：**
- 多层迷宫式推进：每层是一张监视器阵列（网格棋盘）地图，玩家移动探格、踩事件、触发战斗，逐层推进至最终 Boss。
- **鸣徽（Resonium）**：肉鸽圣物式增益。分通用鸣徽（暴击/护盾/支援向）与属性鸣徽（仅当队伍存在对应属性角色才会进入随机池——避免无效选项，**这是肉鸽设计里很值得抄的细节**），另有鸣徽催化（同类合成升级）。
- **压力值（Pressure）与腐化（Corruption）**：探索即施压机制。每踩一个新格 +10 压力；压力满 100 触发**压力过载**——全队扣血 + 从池中随机获得一条**腐化 debuff**（如受伤增加、属性惩罚），可叠多层。某些格子/区域减压力，部分玩家甚至故意踩危险格「刷腐化」换取深层收益（有取舍）。
- 结算：按关卡与进度获得**调查点数**（每周有上限，首通奖励另计），换取养成资源。

**对小游戏的价值**：这是绝区零里「一局一件事」最完整的长肉鸽，但它的核心三件套——格子推进 + 三选一增益 + 压力/腐化惩罚——每个都可以单独裁薄移植。

### 2.3 式舆防卫战（Shiyu Defense）——深渊式限时挑战

高难度常驻终局模式，**定期（约双周）刷新**敌人组合与增益。三个子层（Fandom 验证）：

| 层 | 结构 | 定位 |
| --- | --- | --- |
| 稳定节点（Stable Node） | 前几层，小怪波次，单队 | 门槛层，人人可过 |
| 激化节点（Critical Node） | 7 层起，**每节点两场 Boss 战、两支队伍**：第一队打完的剩余时间**结转并加成第二队得分** | 核心层，S 评级看时间 |
| 争锋节点（Disputed Node） | 更高门槛的进阶层 | 顶尖层 |

- 经典规则：每节点限时约 2 分半量级（社区速通单场 1–2 分钟），打得越快分越高，S/A/B 按时间分档。
- **2.x 版本改版**：从纯限时改为**计分制**——约前 1 分钟为全额计分时间，此后得分乘数持续衰减（「流血」），后期伤害得分大幅缩水；社区评价两极（对低配更不友好）。
- 结构精髓：**「时间换分」+「双队接力结转」**——第一队打得越快，第二队越轻松，鼓励练两支队、放大队伍构建的价值（§6）。

### 2.4 恶名狩猎（Notorious Hunt）——Boss 周本

- 27 级解锁；每周 **3 次奖励次数**，之后重复挑战无奖励（可继续打完成周任务）。
- 结构：单 Boss 高血量对决（部分多阶段），产出 Boss 核心等技能突破材料；难度分档，越高奖励越多。
- 姊妹模式**强敌挑战（Expert Challenge）**：免费、无奖励次数限制的单 Boss 练习场，Boss 机制与当期恶名狩猎同源——**「付费挑战 + 免费练习」分离**是很好的设计（降低挫败感，不稀释挑战价值）。
- 另有**危局强袭战（Deadly Assault）**：周期性多队模式，需 3 支队伍打多个 Boss、按总得分评级——对队伍深度的终极考核。

### 2.5 TV 模式（HDD 走格子）的兴衰——重要教训

**是什么**：开服核心特色。玩家在「电视机」网格上走格子探索空洞，解谜、触发事件与战斗，是叙事载体与差异化标识。

**时间线**（多来源交叉）：
- 三测（2024-04）：已删减大量无演出走格子内容——官方在公测前就在收缩。
- 2024-09-24：官方宣布从主线剧情中移除空洞探索模式（走格子），社区强烈讨论。
- 1.4 版本（2024-12）：主线基本彻底取消走格子，仅零号空洞等模式保留网格探索残影（后也持续简化）。

**为什么被移除**：
- **节奏割裂**：走格子慢节奏与主打的高速动作战斗体验冲突，被玩家诟病「90 分钟走格子是新手灭绝计划」；
- 承担了过多「资源 / 叙事 / 解谜」杂职，而核心爽点（战斗）反而被推迟；
- 留存与口碑压力下的止损动作。

**反面教训**：移除后也有分析（界面新闻等）指出叙事参与感被稀释、差异化标识丢失，社区至今两派争论。

**给小游戏的启示（双向）**：
1. **节奏优先于特色**——任何拖慢核心循环（奶蛙零 = 打击感 + 弹反 + 连段）的系统都会被玩家投票淘汰；
2. 但**特色系统要么做深做成一整条玩法线（如零号空洞之于走格子残影），要么果断砍掉**，不要半吊子保留；
3. 奶蛙零若加任何「局外/局间」层，必须是快节奏的（三选一卡片 < 10 秒），而非探索式的。

## 3. 敌人设计体系

### 3.1 阵营与类别（Fandom 全文验证）

按图鉴（法厄同图鉴 Phaethon's Database）分阵营：

| 阵营 | 说明 |
| --- | --- |
| 以骸 / 以太变异体（Ether Mutants / Ethereal） | 空洞原生怪物，**最常见敌人**；绝大多数弱以太属性 |
| 浪人 / 暴徒（Thugs） | 空洞内犯罪的人类 |
| 侵蚀体（Corrupted） | 被空洞侵蚀转变成以骸的原人类与机械 |
| 叛军（Rebel Soldiers） | 前国防军叛兵，多弱火/物理 |
| 特殊（Special） | 无法归类的剧情 Boss 类 |

按物理构成分三类（决定弱点倾向）：
- **有机体（Organics）**：多弱火/物理；
- **机械体（Machines）**：弱火/物理/电不等；
- **以太体（Ethereals）**：多弱以太。

**弱点属性（Weakness）的作用**：弱属性攻击伤害更高、更容易触发属性异常，同时打失衡也更顺——弱点是「组队选择」与「关卡设计」的接口（见 §6）。

### 3.2 普通 / 精英 / Boss 三档（Fandom 全文验证）

| 档位 | 血量/伤害 | 失衡条 | 失衡后可触发连携次数 | 其他特征 |
| --- | --- | --- | --- | --- |
| 普通（Normal） | 低 | 快 | **1 次** | 受击明显硬直/击退，成群出现 |
| 精英（Elite） | 中高 | 较慢 | **2 次** | 有独立技能组，图鉴金卡 |
| Boss | 极高 | 最慢 | **3 次** | 几乎无受击硬直、闪避窗口小、招式组丰富、**多阶段**；图鉴彩卡 |

**「连携次数随档位增长」是全游戏最优雅的一处设计**：同一个失衡窗口机制，对杂兵是快速清场奖励（1 次连携带走），对精英是两次换人小爆发，对 Boss 是三次连携 + 结尾终结技的完整编排——**难度曲线不靠数值堆，靠机制报酬的层数**。这直接可移植。

### 3.3 Boss 多阶段与失衡表现

- Boss 常见 2–3 个阶段（血量阈值触发）：换阶段时通常有无敌演出、招式组升级、甚至地形/形态变化（如部分 Boss 二阶段叠加远程弹幕或突进技）。
- 失衡状态的表现是全游戏最强的正反馈演出：敌人倒地/僵直、失衡条彩虹闪烁、易伤增伤、**可触发连携技的 UI 提示**，随后连携技镜头切换（每人一镜头的连携演出）——把「数值窗口」做成了「视听高潮」。
- 弱点部位（如部分精英/Boss 的特定部位受击加成）存在于部分敌人，但**不是普遍机制**；绝区零更普遍的「弱点」表达是**属性弱点 + 失衡条**。

### 3.4 为什么「打失衡 → 连携技」是核心循环的枢纽（小结）

1. 它是**攻防转换器**：玩家风险投入（贴近输出、招架）在失衡窗口一次性兑现；
2. 它是**队伍粘合剂**：连携技天然要求切人，单人玩法打不出完整循环，队伍 3 人因此有意义；
3. 它是**难度标尺**：失衡条积累速度 = 关卡难度旋钮，Boss 多阶段重置失衡条 = 每阶段重新开局；
4. 它是**教学压缩器**：新手只要会「把黄条打满 → 按提示连携」就能打出 60% 的系统价值，老手则在临界状态、完美招架、连携顺序上做优化——同一个机制覆盖全技能层。

## 4. 养成系统表层

（只覆盖概念与对 Build 的贡献，不深挖数值）

| 系统 | 概念 | 对战斗构建（Build）的贡献 |
| --- | --- | --- |
| 代理人（Agent） | 等级 + 技能（普攻/闪避/特殊技/强化特殊技/连携技/终结技）+ **核心被动（Core Passive）** | 核心被动是角色定位的锚点（如击破手的被动全在失衡值上），决定「这角色为什么进队」 |
| 音擎（W-Engine） | 武器：基础攻击 + 1 条高级属性（暴击率/攻击%/能量回复等）+ 被动效果 | 被动是 Build 的第二锚点；限定音擎与角色机制强绑定（「专武」），但也存在通用/B 级可替代品，付费深度可控 |
| 驱动盘（Drive Disc） | 6 槽位装备（1–6 号位），主词条 + 至多 4 条随机副词条；**同套装 2 件/4 件套效果** | 遗器式系统，套装效果（如「啄木鸟电音」暴击套、「自由之蓝」异常精通套）是流派成型的主要来源；也是毕业刷取的长线内容 |
| 邦布（Bangboo） | 小机器人伙伴，随队参战，有独立技能（周期性扑击/增益），可升级 | 战斗中的低频补充：不影响循环主干，但提供契合队伍属性的点缀（S 级邦布与队伍属性联动） |

**表层结论**：绝区零的 Build 深度 = 「角色机制（占大头）× 音擎被动 × 驱动盘套装 × 队友组合」。对 5–10 分钟小游戏，只有「角色机制 × 队友组合」值得完整移植；驱动盘套装思想可以降维成「局内肉鸽套装」（鸣徽 2/4 件套思路）。

## 5. 结算与评价

### 5.1 结算界面包含什么

一场战斗（委托/挑战类）结束的结算面板：

- **评级**：C / B / A / S（部分活动模式另有 1–3 星目标）；
- **通关用时**（限时类模式的核心指标）；
- **受到伤害 / 受击次数**（部分模式与关卡目标计入评级）；
- **最高连击数（Max Combo）**与战斗风格统计（招架/完美招架次数等）；
- **总得分**（计分制模式）；掉落资源与首次通关奖励列表。

### 5.2 S 评级由什么决定

- **本质是加权得分制，不是打卡清单**（GameFAQs 玩家实测 + 多来源佐证）：
  - **时间乘数**是最大权重：开局 1 分钟内乘数最高（约 ×5），之后每 15 秒衰减（早期每 15 秒约 −0.8）——打得越快分越高；
  - **受伤情况**：受伤越少分越高，部分关卡有显式目标（如「全员 HP > 30% 通关」）；
  - **战斗风格**：最高连击、招架表现等计入；
  - 不同模式权重不同：式舆防卫战几乎纯时间分；主线委托常有「≤120 秒」这类硬性 S 条件；部分关卡目标是复合条件。
- 直观反馈设计：S 评级在结算动画里有专属演出（磁带/胶片急速旋转抖动），玩家在看到评级前就有预感——**强正反馈预兆**是廉价高效的细节。

### 5.3 对小游戏的价值

结算评价是**性价比最高的系统之一**：成本极低（几个计数器 + 一张面板），却提供「重开一局」的动机（打 S / 无伤 / 高连击），并且把弹反、连段、速杀这些已有机制统一到可比较的分数维度上。

## 6. 队伍构建逻辑

### 6.1 属性 × 特性 两个正交轴

**属性（Attribute）**——经典 5 种：物理（Physical）/ 火（Fire）/ 冰（Ice）/ 电（Electric）/ 以太（Ether）；2.x 起新角色引入特殊属性（烈霜 Frost、玄墨、凛刃、流明等，仅限特定角色）。

属性的作用路径：属性弱点（§3.1）+ **属性异常（Attribute Anomaly）**——攻击积累异常积蓄值，满后触发异常状态（火=灼烧 DOT、冰=冻结/碎冰爆发、电=感电紊乱结算、以太=侵蚀扩散、物理=强击+失衡加成）。

**特性（Specialty）**——基础 6 种（官方英文）：

| 特性 | 英文 | 战场职能 |
| --- | --- | --- |
| 强攻 | Attack | 主输出（直伤/爆发） |
| 击破 | Stun | 快速积累失衡值，主打开失衡 |
| 异常 | Anomaly | 快速挂属性异常，打异常伤害/紊乱 |
| 支援 | Support | 增益、快速支援强化、治疗 |
| 防护 | Defense | 护盾、减伤、嘲讽 |
| 命破 | Rupture | 2.0 新增：强化特殊技后暴伤提升、无视部分物理/以太抗性——介于直伤与击破之间的「特殊技流派」（其后另有更新的第七特性「锋御」） |

### 6.2 三大流派（组队范式）

| 流派 | 核心组合 | 循环 |
| --- | --- | --- |
| **失衡队（Stun 队）** | 击破 + 强攻（+ 支援/防护） | 击破手削韧 → 失衡 → 强攻吃易伤窗口爆发 → 连携/终结技收尾 |
| **异常队 / 紊乱队（Anomaly/Disorder 队）** | 异常 + 异常（+ 支援） | 双属性异常交替触发**紊乱（Disorder）**反应：新异常引爆旧异常，打高倍结算 |
| **直伤队** | 强攻 ×2（+ 支援） | 不依赖失衡窗口，靠暴击/增伤速杀，多用于超练度碾压或异常免疫关卡 |

通用原则：凑**同阵营/同属性的两人羁绊**（激活额外被动），第三人按机制补位。属性弱点（§3.1）决定「带谁」，特性分工决定「怎么打」——**关卡用弱点筛选队伍，特性用职能组合队伍**，两轴缺一不可。

### 6.3 对小游戏的价值

奶蛙零已有「三连战 + Tab 换人接力 + 招式克制」，距离「绝区零味」的组队逻辑只差两块：**敌人弱点属性**（决定出人顺序）与**失衡分工**（谁负责打条、谁负责爆发）。不需要做 6 特性 5 属性，只要给现有 3 个角色 + 3 个对手按这两个轴赋予分工即可。

## 7. 面向「网页小游戏化」的结构裁剪建议

约束条件：单局 5–10 分钟、浏览器 Three.js、已有系统 = 三连战（3 回合对手接力）、招式克制（克制 ×1.25 / 被克 ×0.85）、蓄力必杀、弹反（counter.mjs 完整实现）、连段（combo stage）、换人接力。

### 7.1 保留清单（按性价比排序，只保留 3–4 个）

**① 失衡条 → 连携/终结技循环（最高优先级）**
- 做法：给所有敌人加一条失衡条（黄色 → 满 → 彩虹眩晕）；每招带「失衡倍率」；眩晕窗口内指定招式（蓄力必杀已具备「重击」属性）触发**连携演出**——切到下一名角色打一段固定编排的连携，Boss 允许 3 次、精英 2 次、小怪 1 次。
- 理由：这是绝区零的**身份机制**，且与奶蛙零现有的弹反（完美弹反可大额加失衡值）和换人接力天然咬合——加一个条、一组倍率、一次演出，就激活了三个已有系统。
- 成本：低。无需新系统，只在现有伤害管线旁挂一条 Daze 数值。

**② S/A/B/C 时间乘数结算（性价比之王）**
- 做法：`得分 = 基础分 × 时间乘数（开局 60 秒 ×5，其后每 15 秒衰减）`，叠加受击扣分与最高连击加分；结算面板展示 用时 / 受击 / 最高连击 / 评级；S 时给专属演出（如结算条高速旋转）。
- 理由：成本几乎为零（HUD 已有脏值比对与结算页），直接给三连战加上「重开动机」，并让弹反/连段有统一的比较维度。与现有 E2E 断言体系兼容（评级是纯函数）。

**③ 轻量肉鸽层：鸣徽三选一 + 压力/腐化（第二局的内容来源）**
- 做法：把三连战的三回合之间插入「三选一鸣徽」卡片（< 10 秒，属性鸣徽仅当队伍含对应属性才进池——绝区零的防无效选项细节）；可加轻量压力值（每次受击 +压力，满 100 = 扣血 + 随机腐化 debuff）制造「稳扎稳打 vs 抢时间」的张力；鸣徽做 2 件/4 件套组合致敬驱动盘套装。
- 理由：5–10 分钟单局 + 三选一是肉鸽小游戏的标准解（Hades 房间式），零号空洞验证了这套「增益 + 惩罚」的张力设计；同时是单局游戏唯一可行的「Build 多样性」来源。
- 成本：中。UI 卡片 + buff 求值器，不动物理与渲染。

**④ 敌人三档 + 弱点属性（内容放大器）**
- 做法：敌人分 普通（失衡快、1 连携）/ 精英（2 连携）/ Boss（多阶段、3 连携）三档；给敌人挂弱点属性（奶蛙零 6 环克制可映射为属性克制），弱点属性攻击伤害与失衡值双加成；三连战按「小怪 → 精英 → Boss」梯度 + 弱点轮换编排，逼迫玩家按对手换出战顺序。
- 理由：一个敌人资产按档位 × 弱点复用出 6 种观感，是内容量 ×6 的乘数；「连携次数随档位」让难度曲线不靠数值堆。

**暂不移植**：式舆防卫战双队结转（单局双队成本高，可后续用「三连战剩余时间结转得分」轻量化复刻）；恶名狩猎周本（无长线留存需求）；TV 模式（§2.5 教训：与快节奏冲突，除非做成完整独立玩法线）。

### 7.2 一句话图景

绝区零的结构精髓 = **「把输出窗口化」**：失衡条把时间切成「攒条期/爆发期」，连携技把队伍串进窗口，评级把表现折成分数，肉鸽把窗口循环包装成新的一局。奶蛙零只需移植「窗口」这一件事的四个切面（①②③④），就能获得同一个骨架。
