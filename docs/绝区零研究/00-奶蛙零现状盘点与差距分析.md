## 二、对照绝区零的差距评级

以「ZZZ 战斗循环心脏」（攻击→黄条→眩晕→连携爆发→支援循环→异常紊乱收尾）为标尺：

| ZZZ 核心机制 | 奶蛙零现状 | 差距 | 完成度 |
| --- | --- | --- | --- |
| 失衡条+失衡状态（眩晕/易伤 ×1.5/持续期） | 隐藏 3 格，满即触发、无状态期 | **大** | ~25% |
| 连携技 QTE（子弹时间+选人+多段链+终结演出） | 换人奖励击 | **大** | ~15% |
| 支援点经济（3 点/弹反花 1/连携回 1/大招回满/无点降级） | 无 | **缺失** | 0% |
| 极限闪避（窗口判定+子弹时间+闪避反击） | 普通闪避有无敌帧但无判定 | **中** | ~30% |
| 属性异常+紊乱（5 属性积蓄/5 状态/异类引爆） | 无 | **缺失** | 0% |
| 喧响值+终结技（0-3000/三段等级/清零重来/回支援） | 蓄力终结无资源名分 | **中** | ~30% |
| 零帧换人（打断后摇/重置连段/入场演出） | 2s 冷却+奖励击，无演出 | **中** | ~40% |
| 敌人设计（金光/红光分流/多阶段/弱点） | 单一红闪预警 | **中** | ~20% |
| 手感层（卡肉/震屏/慢镜/伤害数字） | 已相当完整 | 小 | ~70% |
| 队伍与招式差异（16 角色换壳即换招+克制环） | 已实现且是亮点 | 小（缺属性轴） | ~65% |

**综合评估：ZZZ 式战斗体验完成度 ≈ 25%（与制作人「20% 左右」的体感一致）。**
差距的本质：**现有系统全是「孤立机制」，ZZZ 的是「资源循环」**——失衡→连携→支援点→喧响→再失衡的自维持循环一个都没咬合。

## 三、改造优先级结论（依据 01 研究的移植建议 + 本仓架构）

1. **P0 失衡系统**（阶段 A）：一切循环的入口。给对手加可视黄条 + 眩晕状态（易伤 ×1.5 + 定身 + 6s），把现有隐藏 grids 迁移成连续 daze 值。
2. **P0 极限闪避+支援点**（阶段 B）：防御资源化。受击前 iframe 重叠 = 极限闪避（子弹时间 + 闪避反击资格）；弹反吃支援点（3 上限/开战满/无点降级为极限闪避）。
3. **P0 连携技 QTE**（阶段 C）：眩晕期用重击命中 → 子弹时间 + 头像选择链式打击（回合 1/2/3 = 1/2/3 环），每次连携 +1 支援点——循环咬合点。
4. **P1 喧响值**（阶段 D）：0-3000 只增不减，满 [极] 把蓄力终结升级为喧响终结技（×2 伤 + 全程无敌 + 回满支援点 + 清零重来）。
5. **P1 属性异常+紊乱**（阶段 E）：16 角色分 5 属性，命中积积蓄条 → 5 种异常状态；异类异常互挂 = 紊乱引爆。与克制环正交共存。
6. **P2 演出与结算**（阶段 F）：伤害数字分档金色（失衡期）/连携终结横幅/结算多维评价条/第三回合首领红光不可弹反攻击。
