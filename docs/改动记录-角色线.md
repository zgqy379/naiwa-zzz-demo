## 登记与源码不符（待核）

核实时间：2026-11-09（收口线只读核查，未改动源码）

**结论：上表 21:50 的 visualScale 两条登记，尚未落到当前源码。**

证据：

| 检查项 | 结果 |
| --- | --- |
| `src/` 全目录检索 `visualScale` | **0 命中**（`src/game/squad.mjs` 无该字段，`src/main.mjs` 无该引用） |
| `src/main.mjs` 归一化实现（约 157 行） | `const s = member.scale / (size.y || 1);` —— 未乘 `visualScale` 系数 |
| `scripts/capture-show2.mjs`（202、415 行） | 采集时会读 `m.visualScale ?? null`，故只能取到 null |
| `docs/evidence/v3-show2-metrics.json` | `"visualScale": null` 全程为 null，说明采集当时字段已不在运行时对象上 |

判断：属并行覆盖（登记早于实际写入，或写入后被其它线的 `main.mjs` / `squad.mjs` 版本覆盖），非登记笔误。

影响：奶鱼 clip 姿态的高度补偿未生效，在第二轮机位（distance 3.8 / fov 40）下角色视觉比例可能仍偏高；不影响构建与运行。

处置原则：

1. 以上两条原始登记行**保留不删改**，作为改动意图留痕。
2. 重新落地时**新增一行**，格式 `| 2026-11-09 | src/game/squad.mjs, src/main.mjs | 第三轮：补回 visualScale（默认 1），归一化乘该系数 | ... |`，并在本段标注「已补回 + 构建 hash」。
3. 补回动作触及 `src/main.mjs`（共享热点），须遵守 `AGENTS.md` §3：先登记 → 最小改动 → `node --check` → 构建 → 记录 hash。
4. 补回前先确认无其它线正在写 `src/main.mjs`，避免二次覆盖。
