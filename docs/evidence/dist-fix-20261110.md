## 2. 根因与修复

| 项 | 内容 |
|---|---|
| 缺陷 | 片元着色器 uniform 声明块漏了 `uKeyDir`，但 `shader.uniforms.uKeyDir` 已注入且 GLSL 使用 `normalize(uKeyDir)` → `Shader Error 1282 'uKeyDir' : undeclared identifier` → NPR 程序无效 → 角色整体不渲染（只剩暗色块） |
| 修复 | `src/render/npr.mjs` **L124** 补回 1 行 `uniform vec3 uKeyDir;`（与 L89 注入、L138 使用配对） |
| 复核 | `grep -n "uniform vec3 uKeyDir;" src/render/npr.mjs` → **`124:         uniform vec3 uKeyDir;`** |
| 语法 | `node --check src/render/npr.mjs` → 通过 |
| 源码 mtime/sha256 | `src/render/npr.mjs` 10,246 B / 2026-11-09T16:58:16Z / sha256 前 16 位 `3426de42…`（构建前三次轮询的 src 合并哈希均为 `78f641b2d2ee1c5330e68382`，窗口稳定 28s） |
| 产物内确认 | `.tmp-dist-fix/assets/index-Bdgxfg97.js` 中 `grep -c "uniform vec3 uKeyDir;"` → **1**（GLSL 字符串在 minify 后保留） |

## 8. 录制建议（沿用 `dist-readiness-20261110.md`，变化点单列）

**结论：画面已可录，帧率仍是唯一瓶颈。**

1. **必带启动参数**（默认后端本轮虽到 12.67fps，但历史 1.34fps，不可依赖）：
   ```
   --use-angle=d3d11 --use-gl=angle
   --enable-gpu --ignore-gpu-blocklist --enable-gpu-rasterization
   --disable-background-timer-throttling --disable-renderer-backgrounding
   --disable-backgrounding-occluded-windows
   ```
2. **画布档位**（实测，未实测组合不臆造）：

   | 档位 | 画布像素 | 实测 fps | 备注 |
   |---|---|---|---|
   | 高画质 | 2000×1250（1600×1000@1.25） | **14.61**（本轮 angle） | 最锐，只够 15fps |
   | 中画质 | 1000×625（800×500@1.25） | 46.21（上一轮 angle，未变源码路径） | 过 30fps，画质明显降 |
   | 备选**未实测** | 1920×1080 / 1280×800 @dpr1.0 | — | 需先实测；改 dpr 时确认画布真的变了（`Emulation.setDeviceMetricsOverride` 改 dpr 不改渲染分辨率，`renderer.setPixelRatio` 只在构造期取一次） |

3. **容器按 30fps**；不追 60/120fps（空页 rAF 120fps，游戏本体受 composer+MSAA+上屏同步链限制）。
4. **录制纪律（不变）**：锁死相机（不拖拽，拖 600px 会让 `rel` 方位角转 68.75°）；不按 `[` `]`、`N`（重编译材质掉帧尖峰）；不进设置改画质；不按 `Tab/Q/E/数字键`（换壳即换招）。
5. **若坚持 2000×1250**：15fps 实录 → **0.5× 慢放 + 重定时 30fps**（32s 成片需 ~64s 素材；低帧率下逻辑时间本就慢放 ≈0.45×）；不建议补帧（击发残影会拖尾）。
