# 奶蛙零 · UI/UX 深度挑刺审查

> 审查范围：`src/ui/hud.mjs`、`src/ui/screens.mjs`、`src/ui/screens.css`、`src/ui/style.css`、`index.html`、`src/main.mjs`（输入/流程）、`src/ui/portrait.mjs`、`src/ui/titlefx.mjs`
> 证据：`docs/test-shots/` 全部 30+ 张实测截图（含 20 张 FAIL 截图）
> 基准：绝区零 UI 体系（见 `docs/绝区零界面体系研究.md`）

---

## 问题清单（按严重度排序）

### 🔴 严重（影响可用性）

1. **选人界面立绘全部丢失，角色无法辨认** — `screens.mjs:97-147` 的 `_buildSelectList` 异步生成 16 张缩略图，但 `02-select.png`、`03-select-switch.png` 及全部 FAIL 截图（`16 只角色全部加载-FAIL` 等）显示 16 张卡片**全是纯色渐变块**，右侧展示台（`.showcase-img`，220px 高）**完全空白**，只剩名字+四条数值。玩家选人只能读名字，无法用外观区分 16 只角色——这是选人界面的核心功能失效。且 `window.__portraitStage` 写了却**没有任何 UI 显示加载进度**，玩家看到的是"卡住"而非"加载中"。建议：先显示骨架屏/进度条（`__portraitStage` 已有数据，接上去即可），失败时回退到 3D 实时渲染展示台而非空块。

2. **主界面立绘同样丢失，且与 Logo 重叠** — `06-back-title.png` 中 `.title-char` 位置显示的是巨大的 alt 文本"奶蛙"（图片加载失败），`01-title.png` 中角色立绘右移后仍与居中 Logo「奶蛙零」右缘相碰。根因同 #1（portrait 异步失败无回退）。`.title-char`（`right:8%; width:46%; height:88%`）与 `.title-inner`（`max-width:520px` 居中）在宽屏必然重叠，无 z-index/位移保护。建议：立绘失败时隐藏 `.title-char` 而非留 alt 文本；给 `.title-inner` 加 `z-index:2` 或给立绘加 `left` 偏移。

3. **"丁尼"直接照搬绝区零货币名** — `main.mjs:616-617` 结算奖励写 `"丁尼 ×80"`。「丁尼」是绝区零的专属货币名，属于研究文档 §八 明令"不可复制具体表达"的范畴。这是黑客松作品，IP 风险实打实。建议改成自造词（如「奶币」「蛙丁」）。

4. **弹反（博弈核心）无任何 HUD 引导** — `counter.mjs` 的 `openWindow()` 只改内部 state，`main.mjs:467-471` 开启 0.25s 弹反窗口后**没有任何 HUD/特效提示**。截图中受击画面（`受击动画触发-FAIL.png`）看不到任何"可弹反"提示。玩家不知道何时该按 Shift 弹反，博弈机制等于隐藏。绝区零的弹反有明确的敌人闪光+UI 提示。建议：窗口开启时在屏幕中央/敌人头顶显示「弹反!」提示 + 按键高亮（复用 `.key.urgent`）。

5. **血条无数字、无低血警告** — `hud.mjs:123-124` 只更新 `width%`，两条血条都没有 `100/100` 数值文本；`main.mjs:551-563` 的 `hud.set` 也没有传低血状态。玩家无法判断"还能挨几下"，低血时血条仍是黄色、无脉冲/无红晕/无音效。动作游戏这是硬需求。建议：血条旁加数值；HP<30% 时血条变红 + 屏幕边缘红晕 + 心跳音。

6. **`canCharge`/`canSwap` 是死代码，按键标签与实际玩法不符** — `hud.mjs:80` 硬编码 `class="key glow"` 让「空格」键**永久发光**，但 `canCharge` 在 `main.mjs` 里从未被置 true（全仓搜索只有初始化 `false`）。标签写「笑(按住蓄力)」，但实际 `空格` = `onAttackInput()`（连段攻击），且 `movement` 里 `jump: keysDown.has(" ")` 让空格**同时是跳跃键**。玩家被引导去"按住蓄力"，实际触发的是攻击+跳跃。建议：删掉不存在的蓄力机制，或真正实现它；空格只保留一个语义。

7. **"拖动旋转"是死功能** — `main.mjs:421-428`：`camAngle` 累加后**从未被读取**，相机没有任何使用 `camAngle` 的代码。底部帮助文本却写着「拖动旋转」。且 `mousedown` 绑在 `window` 上、不判断点击目标，**点任何 UI 按钮都会触发拖拽**。建议：要么把 `camAngle` 接进相机，要么删掉提示；同时 `mousedown` 加 `e.target === canvas` 判断。

### 🟡 中等（影响体验）

8. **HUD 信息层级倒置** — 计时器 `.timer-num` 34px 白色带金晕（`style.css:35-39`）是全场最大最亮的元素，但战斗不限时（`tuning.mjs:6`），计时器最不重要；左上角永久品牌 Logo「奶蛙零 VOL.0」占据黄金位置（`hud.mjs:46-49`），把玩家血条挤到 `top:76px`。绝区零战斗 HUD 无 Logo。建议：砍掉战斗 HUD 里的 Logo，计时器缩小降级。

9. **我方血条用品牌黄，与"可触发"发光同色** — 我方血条 `#f5c542→#ffd97a`（`style.css:68`）与品牌黄、按键 glow 金完全相同。玩家血条看起来像装饰/高亮，而非生命状态；对手血条粉红反而更醒目，**视觉重心落在敌人身上**。建议：我方血条改绿/白，与品牌黄解耦。

10. **「连携 0/3」分母是硬编码 bug** — `hud.mjs:125` 模板 `` `连携 ${s.combo}/3` ``，但 `combo` = `battle.comboCount`（连携链数，无上限），`/3` 抄的是 `balanceGrids=3`，语义对不上。玩家看到"连携 5/3"会困惑。建议：去掉分母或改成实际最大值。

11. **连段阶段不可见** — `combo.mjs` 有三段（轻击/重击/终结），但 HUD 只显示"连携 X/3"（那是链数），**没有当前连段段数/终结技就绪提示**。玩家不知道第几段、不知道终结技何时可用。绝区零有明确的连击数+终结提示。建议：加连段段数指示（如 ●●○）+ 终结就绪闪烁。

12. **术语混乱：接力 / 换壳 / 连携 / 壳** — 同一机制四个名字：HUD 键位写「接力」（`hud.mjs:82`）、帮助文本写「换壳」（`hud.mjs:91`）、连携芯片写「连携」、角色芯片写「壳」（`hud.mjs:62-66`）。新玩家完全无法建立心智模型。建议：统一为"换人"或"连携"，删除"壳"这种内部黑话。

13. **开发者调试信息漏进战斗 HUD** — 左下角常驻「模式：NPR / 色调分离：3 档」（`hud.mjs:85-88`），右下角常驻「N 切换 PBR/NPR · [ ] 档数 · Tab/Q/E 或 1–9/0 换壳 · 拖动旋转」（`hud.mjs:90-92`）。这些是开发快捷键，不该占据战斗 HUD。且字体 11px、`#6a6a80`，对比度约 2.8:1，**低于 hud.mjs 注释里自称的 4.5:1**。建议：移入暂停菜单或设置页。

14. **键位条顺序与标签都反直觉** — `hud.mjs:78-83` 顺序为「A/D 移动 → 空格 笑(按住蓄力) → Shift 躲 → Tab 接力」。动作游戏最重要的攻击键排第二，移动键排第一；「A/D 移动」只标 A/D 漏了 W/S；「Shift 躲」没提弹反（博弈核心）。建议：攻击置首，移动移出技能条，闪避键标注「闪避/弹反」。

15. **选人卡片布局低效、颜色无法区分** — `screens.css:126-130` `grid-template-columns: repeat(auto-fill, minmax(140px,1fr))` 在 1100px 容器里撑成 4 列 × 4 行，卡片被拉得很大但图只有 90px 高，纵向空间浪费。16 只里 6 只颜色接近白/米（`#fff0c2`/`#efe8d8`/`#f7f1e3`/`#fdf3e0`/`#f0e0a8`/`#f2d8de`），卡片渐变几乎一样，**失去颜色编码意义**。建议：改竖排小卡列表（绝区零式），卡片用角色主题色做边框/角标而非整块渐变。

16. **展示台是静态 2D 图，不是设计文档承诺的 3D 可旋转模型** — `docs/绝区零界面体系研究.md` §三明确写"右侧：3D 展示台（角色模型，可旋转）"，实现却是 `portrait.mjs` 离线渲染的一张 2D dataURL。切换角色时没有"转身/重新摆姿势"，只是换张图。建议：选人界面直接用主渲染器渲染 3D 模型（场景已有），或至少让 2D 图有角度切换。

17. **无暂停/退出战斗途径** — 战斗中无 Esc 暂停、无退出到主界面入口，只能被打死或击败对手。演示/比赛场景下这是硬伤。建议：Esc 打开暂停菜单（继续/设置/返回主界面）。

18. **无伤害数字、无敌人信息、无胜利条件** — 命中只有拟声词（"终结!"）无伤害数值；对手血条无数字、无名字（只写"对手"）、无等级；HUD 无目标提示（"击败对手"）。玩家不知道还要打多久。建议：加飘字伤害数字 + 敌人名 + 目标提示。

19. **失衡格与连携芯片语义重叠且都太小** — 3 个失衡格 28×8px（`style.css:75-81`），填满后触发连携，芯片写「连携 X/3」。两个indicator 描述同一循环却用不同词，且都极小。建议：合并成一个"失衡→连携"进度条，或让连携芯片在触发时放大居中显示。

20. **设置页无可访问性/按键自定义** — `index.html:89-121` 只有渲染风格/色调分离/音量/画质。无字号调节、无色盲模式、无按键映射。色盲层面：失衡格 pink `#ff3d8b` 与对手血条 pink 同色，仅靠位置区分，红绿色盲难以分辨。建议：加字号/色盲选项；失衡格改形状或加图标而非纯颜色。

### 🟢 轻微（打磨项）

21. **结算界面无角色立绘、无动态数字** — `05-result.png` 只有 S 等级 + 四个数值 + 三个文字 chip。研究文档 §五要求"动态数字滚动 + 奖励卡片弹出 + 背景立绘"。建议：至少加数字滚动动画和奖励卡片式布局。

22. **界面切换有 ghosting** — `screens.css:10-15` 所有 `.screen` 都是 `position:fixed; inset:0`，切屏时旧屏 `scale(1.04)` 淡出、新屏淡入，中间态两屏叠加。建议：旧屏直接 `visibility:hidden` 或缩短过渡。

23. **Toast 与键位条位置接近** — `#toast` `bottom:90px`（`screens.css:287`）紧邻底部键位条（`bottom:22px`），战时提示「奶粉 出战！」可能与键位条视觉打架。建议：toast 上移或改为顶部居中。

24. **主界面立绘"呼吸"动画廉价** — `screens.css:314-317` `charBreath` 只是整图 translateY ±8px，看起来图像在漂浮而非呼吸。建议：改 scale 微动或换成 3D 模型 idle 动画。

25. **画布无拖拽光标提示** — 拖动旋转（即便修好）没有 `cursor:grab`，玩家发现不了。建议：`#gl { cursor: grab }`。

26. **无小地图/目标指示** — 研究文档 §四右上应为"小地图/任务提示"，实现里右上是回合数「7/16」。建议：右上改目标提示。

## 与绝区零的差距

- **战斗 HUD 信息分区**：绝区零左上是"角色头像+血条+能量+喧响"，本项目左上是"Logo+血条"，缺头像/能量/喧响，多一个不该有的 Logo。右下技能栏绝区零是图标+冷却，本项目是文字 kbd 条，无冷却显示。
- **引导逻辑**：绝区零"可触发技能发光"是**动态**的（终结就绪才闪），本项目 `glow` 是**静态硬编码**，永远亮，引导失去意义。弹反提示绝区零有敌人闪光+UI，本项目完全没有。
- **反馈节奏**：绝区零命中是"顿帧+震屏+白闪+伤害数字+拟声词"五件套，本项目缺**伤害数字**，弹反成功无专属反馈。
- **选人界面**：绝区零是竖排卡片+3D 可旋转展示台，本项目是 4×4 大色块网格+空白展示台（立绘丢失）。
- **结算界面**：绝区零有动态数字滚动+奖励卡片弹出+立绘，本项目是静态文字。
- **术语一致性**：绝区零全游戏统一"连携/换人/终结"，本项目"接力/换壳/连携/壳"四名并存。

## 优先修复建议（Top 5，按性价比排序）

1. **修立绘加载 + 加加载态**（#1/#2）：`portrait.mjs` 失败时回退到 3D 展示台或至少显示进度；这是选人/主界面的门面，当前是坏的。工作量小（`__portraitStage` 已有数据），收益最大。
2. **统一术语 + 修键位标签**（#6/#12/#14）：删掉不存在的"蓄力"，空格只留攻击；"接力/换壳/壳"统一成"换人"；键位条按 攻击→闪避/弹反→换人 排序。纯文案改动，零风险，直接提升可读性。
3. **加弹反 HUD 提示**（#4）：`counter.openWindow()` 时在屏幕中央显示「弹反!」+ Shift 键 `urgent` 闪烁。这是博弈核心玩法的唯一入口，不修等于玩法隐藏。
4. **血条加数字 + 低血警告**（#5/#9）：两条血条加 `cur/max` 文本；HP<30% 变红+红晕。我血条改绿色/白色，与品牌黄解耦。动作游戏基本盘。
5. **清 HUD 调试信息 + 降级计时器**（#8/#13）：把「模式/色调分离/快捷键帮助」移出战斗 HUD；计时器从 34px 缩到 18px 以下；砍掉战斗 HUD 的 Logo。视觉噪音立刻下降，信息层级回归血条/连段。
