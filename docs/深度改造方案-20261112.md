# 奶蛙零 ×绝区零 深度改造方案

> 日期：2026-11-12｜依据：`docs/绝区零研究/00~03`（机制数值经 ≥6 独立来源交叉验证）
> 基线：`freeze-2026-11-11-final`（E2E 28/28）｜截止：2026-11-19 19:00
> 目标：把「孤立机制堆」改造成「ZZZ 式资源循环」——失衡→连携→支援点→喧响→再失衡全链咬合，战斗体验完成度 25% → 70%+。

## 0. 范围裁决

| 决策 | 结论 | 理由 |
| --- | --- | --- |
| 保留三连战结构 | ✅ 并升级语义：回合1=精英(连携1环)/回合2=精英(2环)/回合3=首领(3环+狂暴阶段) | 与 ZZZ「1–3 波+Boss」同构，现有代码直接复用 |
| 鸣徽三选一（回合间轻肉鸽） | ✅ 做（阶段 G） | 02 研究性价比 Top3；DOM 覆盖层 + buff 池，成本低、重玩价值高 |
| TV 模式/多波次房间推进 | ❌ 不做 | TV 教训：局外层必须快；三连战已承担波次结构 |
| 结算改造 | ✅ 时间乘数 + 维度扩充，但**保持 4 个 .result-stat**（E2E 断言 count==4） | 多维评价放独立 DOM 区（同 result-rounds 模式） |
| 支援点/喧响/异常与现有弹反·克制·蓄力终结的关系 | **挂接升级**，不推倒 | E2E 28 条绑定现有路径（蓄力 dmg>40、hp=0 结算、克制表、三连战），只能放大不能拦截 |

## 1. 阶段 A：失衡系统（ZZZ 循环的心脏）

**新文件 `src/game/stagger.mjs`**：
- `StaggerSystem { value 0-100, state: normal|staggered, timer, resist }`
- `gain(amount)`：×成员 gridMul ×克制 1.25（风格克对手时）×弱点 1.5；眩晕期间免疫；结束后 resist 阈值成长（再满需 120%）
- 满 100 → **失衡状态 6.0s**：对手 AI 定身、当前前摇取消、**受伤 ×1.5**、模型瘫软（anim 前倾 + 降饱和 rim）+「失衡!」横幅
- 结束 → value 归零，state normal

**失衡积累表**（网页节奏调校，源：01 研究 §三移植建议）：

| 行为 | 积累 |
| --- | --- |
| 连段轻/中/重击命中 | +6 / +9 / +14 |
| 三段终结命中 | +16 |
| 蓄力终结命中 | +22 |
| 弹反成功（惩罚击） | +18（ZZZ：招架积累「大量」失衡） |
| 闪避反击 | +12 |
| 强击异常 | +15 |

**UI**：对手血条下方**黄条**（0-100%，白色→黄→满条闪烁）；失衡期显示「易伤 ×1.5」徽标。现有 3 格 grids UI 替换为该黄条（`hud.set({daze, staggered})`）。
**E2E 影响**：28 条不触碰 grids → 安全；`battle.grids` 字段保留但停写（兼容旧探针）。
**调试口**：`__npr.stagger()`。

## 2. 阶段 B：极限闪避 + 支援点经济

**新文件 `src/game/assist.mjs`**：`AssistSystem { points:3(cap3), dodgeCounterT:0 }`

**极限闪避**（改 `main.mjs` 对手命中判定分支）：
- 命中瞬间玩家 `move.hasIframe` → 不再是"无事发生"，触发：慢镜 ×0.3 持续 0.5s（`cinematic.slowmoT=0.5`）+「极限闪避!」弹出 + 喧响 +150 + 失衡 +5 + **闪避反击资格 1.5s**
- 闪避反击：资格期内攻击输入 → 瞬发重击（18×damageMul×克制倍率，heavy 档 hitstop/震屏，期间无敌）+ 失衡 +12 + 喧响 +120
- 数值依据：01 研究 §七（窗口网页版放宽至 80–120ms → 复用现有 0.32s iframe 与攻击落点时刻重叠判定，天然成立）

**支援点**：
- 弹反成功**消耗 1 点**（`counter.tryCounter` 前置检查）；**无点时按 Shift 弹反 → 自动落空为普通闪避 → 若掐准时刻即极限闪避**（ZZZ 降级路径，零额外代码——B 阶段极限闪避已实现）
- 回复：连携技每次 **+1**（阶段 C）、喧响终结技 **回满 3**（阶段 D）
- **UI**：我方血条下 3 个支援点亮格（ZZZ 支援按钮 3 格样式）
- E2E：无弹反断言用例；`counter.tryCounter()` 签名兼容（新增 points 检查在 main 侧调用处）

## 3. 阶段 C：连携技 QTE（爆发窗口）

**触发**：对手失衡状态中，玩家**重击级命中**（三段终结 / 蓄力终结 / 闪避反击）→ 开启连携 QTE：
- `battle.chainQte = { active, counts（回合1/2/3 = 1/2/3）, t: 3.0, used:Set }`
- 子弹时间 ×0.3 贯穿窗口（slowmoT=3）；玩家输入被门控（连段/移动暂停）；对手定身（已失衡）
- **DOM 覆盖层 `#chain-qte`**：3 个队员头像 chip（轮换顺序下三位）+ 倒计时条 + 漫画风斜切横幅「CHAIN ATTACK」
- 选择：**数字键 1/2/3 或点击 chip**（QTE 期间数字键改道连携选择）；每名成员本场限选一次
- 每环演出：换模型可见性 → FINISHER 动作 → cinematic 推近 + 一帧白闪 + hitstop → 伤害 = **24 × damageMul × 克制倍率 ×1.5（失衡易伤）**；**+1 支援点、+300 喧响**
- 最后一环 = **连携终结**：慢镜 1.2s + 全屏闪 + 「CHAIN FINISHER」横幅 + 伤害 ×1.5
- 结束：环数用尽 / 3s 到时 / Shift 取消
- **循环咬合**：连携 +1 支援点 + 300 喧响 → 支撑下一次弹反与终结技（01 研究 §四移植建议 3）
- E2E：新增用例（调试口 `__npr.stagger` 置满 → 重击 → 断言 QTE 激活 → 数字键 → 断言掉血+points+1）；28 条旧用例不受影响（QTE 只在失衡后出现）

## 4. 阶段 D：喧响值与终结技

- `battle.decibel 0-3000`，**只增不减**；等级 [喧]1000 / [特]2000 / [极]3000
- 获取：轻/中/重击 +40/60/90，终结 +150，蓄力 +200，弹反 +200，极限闪避 +150，闪避反击 +120，连携环 +300，破坏箱 +20（01 研究 §五：命中与高质量行为积累）
- **满 [极] 后蓄力终结升级为喧响终结技**：伤害 **92 × damageMul × 冲击 × 克制**（≈2× 蓄力终结）+ 全程无敌（battle.invulnT）+ 慢镜 1.4s + 全屏白闪 + 「ULTIMATE」横幅；**消耗全部喧响 + 回满 3 支援点**（ZZZ 循环闭环）
- 未满 [极]：蓄力终结行为与今日完全一致（**E2E #15 判据 dmg>40 不破坏**；若满级则更大，仍 >40 ✓）
- UI：蓄力条旁 3 段喧响槽（金色）

## 5. 阶段 E：属性异常 + 紊乱 + 弱点

**16 角色属性表**（加入 `game/squad.mjs` FAMILY，按风味映射）：
- **物理→强击**：奶蛙、奶狗、西格玛
- **火→灼烧**：奶茶（热茶）、奶鸡、奶屎
- **冰→碎冰**：奶鱼、豆奶、奶兔、奶蛋
- **电→感电**：奶鼠、奶瓶、小奶蛙
- **以太→侵蚀**：奶粉（迷障）、奶猫、奶豆

**积蓄**（新文件 `src/game/anomaly.mjs`）：对手 5 条独立积蓄（各 0-100，2/s 衰减），命中 +10×弱点1.5；满 → 异常状态 10s（阈值抗性成长：重复施加 +25，上限 200——01 研究 §六 [中]）：
- **强击**：瞬发 30×damageMul 爆发 + 失衡 +15 + 硬直 0.8s
- **灼烧**：每 1s 一跳 5×damageMul（10 跳）
- **碎冰**：冻结 1.5s（AI 定身）→ 碎冰爆发 25×damageMul + 失衡 +10（无暴击系统，霜寒暴伤 +10% 不移植，如实记录）
- **感电**：8s 内玩家每次命中追加 4×damageMul（至多 10 次）
- **侵蚀**：8s 内受伤 +15%

**紊乱**：已带异常 A 时施加异类异常 B → 立即引爆（A 剩余 DoT 一次结清 + **20×damageMul 紊乱段**）+ 清双状态，「紊乱!」大字横幅（01 研究 §六：剩余 DoT 引爆 + ~450% 奖励段的定性结构）。
**弱点属性**：每回合对手随机弱点属性（toast + HUD 图标显示）：该属性命中伤害 ×1.3、失衡积累 ×1.5（02 研究：弱点双加成）。
**与克制环共存**：风格克制管直接伤害倍率（现有），属性轴管异常与弱点——正交不冲突。
**UI**：失衡黄条下属性色积蓄细条 + 异常状态 chip（倒计时）+ 弱点图标。
**E2E**：新增异常触发与紊乱引爆用例（`__npr.anomaly()` 调试口）。

## 6. 阶段 F：演出、结算与首领

- 伤害数字分档：失衡期命中数字金色（hitflash 加 gold 类）
- 结算：**时间乘数**（mult = clamp(5 − elapsed/30, 1, 5)，02 研究 ×5 起 15s 衰减的网页化）× 基础分（伤害 + 连击×20 + 弹反×30 + 连携×40 + 异常×30）；评级阈值不变；**统计区保持 4 项**：造成伤害 / 最大连击 / 连携·支援 / 受到伤害；多维评价条放独立 DOM
- 首领（回合 3）血量 <50% 狂暴：攻击 CD ×0.6 + 追加**红光不可弹反攻击**（`counter.openWindow({parryable:false})`，红闪替代金闪，弹反分支禁用、只能闪避）——ZZZ 金光/红光分级预警
- 邦布/多波次等不做（范围裁决）

## 7. 阶段 G：鸣徽三选一（轻肉鸽）

- 回合间（advanceRound 内）暂停战斗 → DOM 覆盖层 3 张卡片（<10s，02 教训：局外快节奏）
- Buff 池 9 选 3 随机：攻击 +15% / 失衡积累 +20% / 异常积蓄 +30% / 喧响获取 +20% / 闪避无敌 +0.1s / 弹反窗口 +0.05s / 立即回复 30% 生命 / 连携伤害 +25% / 支援点回满
- 存 `battle.buffs`，结算展示持有鸣徽

## 8. 实施顺序与门禁

```
A 失衡 → B 极限闪避+支援 → C 连携QTE → D 喧响 → E 异常紊乱 → F 演出结算首领 → G 鸣徽
```
每阶段完成即跑：`node --check`（改动文件）→ `npm run lint` → `node tests/run-e2e.mjs`（28+ 全绿）→ git commit（阶段独立提交，可回滚）。
改 `src/main.mjs` 前在 `docs/改动记录-角色线.md` 登记（契约 §3）。
最终：构建 dist（§4：确认工作区安静）→ 实拍 → §6 交接 → 报告书单独立项修订（§8）→ 部署属制作人决策（§5 闸门不动）。
