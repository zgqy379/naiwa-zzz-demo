# 绝区零界面体系研究（设计参考）

> 依据：公开资料（官网、玩家社区、UI 分析文章）整理。
> 用途：为「奶蛙零」的界面设计提供参考。**只借设计语汇，不复制具体表达。**

---

## 一、界面体系总览

绝区零的界面分为 5 大层级：

```
启动层 → 主界面层 → 角色/养成层 → 战斗层 → 系统层
```

| 层级 | 界面 | 说明 |
|---|---|---|
| **启动层** | 登录、健康忠告、加载页 | 进入游戏前 |
| **主界面层** | 主菜单、手机系统、地图 | 游戏入口 |
| **角色/养成层** | 角色栏、角色详情、技能、装备、影画 | 养成系统 |
| **战斗层** | 战斗 HUD、敌人面板、连携选择条、终结演出、结算 | 核心玩法 |
| **系统层** | 调频（抽卡）、商店、背包、任务、笔记、设置、好友 | 支撑系统 |

---

## 二、主界面（标题画面）

### 视觉特征
- **主角立绘**（大幅）+ 大标题「绝区零」+ 版本号
- **背景**：新艾利都街景（动态，有视差/粒子）
- **快捷入口**：战斗、角色、卡池、商店、活动等图标排列
- **氛围**：磁带未来主义 + 街头涂鸦 + 霓虹

### 动效
- 角色**呼吸/转身**（不是静态图）
- 背景**视差滚动**
- 霓虹**闪烁**
- 按钮**hover 发光**

### 配色
- 深色底（黑灰）+ 亮色点缀（角色主题色）
- 「警戒带」元素（亮色斜纹）

---

## 三、角色选择界面

### 布局
- **左侧**：角色卡片列表（竖排）
- **右侧**：3D 展示台（角色模型，可旋转）
- **底部/侧边**：属性面板（攻击/生命/防御/类型）

### 交互细节
- 切换角色时：**角色转身 + 重新摆姿势**（不是切相机）
- 卡片选中态：高亮 + 主题色边框
- 详情页：技能列表 + 操作说明 + 升级

### 配色
- 深色底 + 角色主题色「警戒带」
- 信息层级：1 级（大字白色）> 2 级（灰色小字）

---

## 四、战斗 HUD

### 布局（关键信息分区）
| 位置 | 内容 |
|---|---|
| **左上** | 角色头像 + 血条 + 能量条 + 喧响值 |
| **右上** | 小地图 / 任务提示 |
| **右下** | 技能栏（攻击/闪避/切人/终结技） |
| **右侧** | 连携提示（可触发时发光） |
| **屏幕中下** | 连携选择条（倒计时时） |
| **敌人身旁** | 血条 + 失衡条 + 易伤倍率 |

### 引导设计
- 可触发技能：**发光/闪烁**
- 终结技就绪：图标**闪烁**
- 连携可用：角色头像**高亮**

### 反馈
- 顿帧（hitstop）
- 震屏（trauma-based）
- 闪屏/白闪
- 慢镜（子弹时间）
- 粒子 + 冲击波 + 速度线

---

## 五、结算界面

### 内容
- 战斗结果（胜利/失败）
- 评价（S/A/B/C）
- 奖励（经验、材料、货币）
- 用时/连击数/最大伤害

### 视觉
- 大字结果 + 动态数字滚动
- 奖励卡片逐个弹出
- 背景模糊 + 角色立绘

---

## 六、音效体系

| 类型 | 内容 |
|---|---|
| **BGM** | 主界面（轻松）、战斗（紧张）、结算（舒缓） |
| **打击音** | 轻击/重击/终结（不同音色） |
| **UI 音** | 点击/悬停/确认/取消 |
| **环境音** | 街道（车流、人声、风声） |
| **语音** | 角色台词（命中/受击/胜利） |

---

## 七、本项目（奶蛙零）的取舍

**做**（完整游戏骨架）：
- 主界面 → 选人 → 战斗 → 结算（4 个核心界面）
- 战斗 HUD 精修
- 音乐音效（Web Audio 合成）

**不做**（超出 10 天范围）：
- 抽卡/商店/背包/任务/社交等系统层
- 地图/手机系统
- 角色养成（装备/技能树）

**理由**：比赛评分维度是「技术栈 30% + 有趣 25% + 创新 20% + 完成度 20% + 传播 5%」——**核心流程完整 + 战斗好玩**比「系统多」更重要。

---

## 八、授权边界（重申）

| 可借 | 不可借 |
|---|---|
| 界面**布局逻辑**（信息分区） | 具体**版式/配色** |
| 「按键发光引导」交互 | 具体 **UI 素材/图标** |
| 「深色底+亮色点缀」语汇 | **警戒带/字体/装饰元素** |
| 「角色转身摆姿势」交互 | **角色立绘/3D 模型** |
| 「顿帧/震屏/慢镜」反馈 | **音乐/音效样本** |

**本项目的实现**：全部**自绘 + 程序化生成**，不复制任何具体素材。
