2.1 Aholo  Lux3D是什么 ​
Aholo Lux3D 是一款群核科技自研的3D生成模型，提供文生 3D、图生 3D、材质重绘、模型后处理等核心能力。​
端到端生成：在单物体生成领域，具备高精度几何、材质和3D高斯生成的一站式能力​
材质表现能力佳：在木材、石材、金属、塑料、瓷器和有丰富文字表现Logo细节纹理的材质领域，达到行业头部水平​
2.2 能力边界 ​
以下能力评估，截至时间为26年8月22日。​
边界维度​
适合场景​
当前边界 / 不适合场景​
图案与文字​
大图案、大色块、大 Logo 保留相对稳定​
小字、成分表、可读标签等容易出现模糊、变形或错字​
几何结构​
主体轮廓清晰、结构相对明确的物体​
复杂背面、多配件穿插、明显凹凸、雕花、浮雕等复杂结构稳定性有限​
材质​
对金属、陶瓷、塑料、纸张、石材、皮革等主要材质表现较好​
复杂高反射金属、精细印花等场景需要实测确认；长毛、缝线、毛绒类材质效果不稳定；透明材质当前表现不够稳定​
人物与植物​
可用于部分概念预览和非关键资产尝试​
人物脸部、复杂五官，以及枝叶繁密的植物稳定性较弱，不建议作为默认生产方案​

节点画布模式适合详细操作​
节点编辑器简介：​
专业版以「节点编辑器」组织生成流程。进入后可选择预设工作流，或自定义节点流程。​
与精简版相比，最大的不同是可以查看每个节点的输出，并将中间结果复用到其他流程。​
2.4.1 选择预设工作流——进入专业版后，提供若干预设工作流可供选择：​
预设工作流​
具体操作概述​
示例截图​
在材质重绘页面的当前模型区域，点击上传模型图标，以导入本地文件或从资产库选择3D模型。​
图生 3D​
通过上传单张或多张图片快速生成对应的三维模型。​
图片输入节点 → Aholo Lux3D 节点 → 预览节点 → 导出节点​
文生 3D​
结合文本提示词与参考图片，描述目标模型的外观、风格、材质等特征，系统将根据输入内容生成对应模型。​
提示词节点 / 图片输入节点 → 生图节点 → Aholo Lux3D 节点 → 预览节点 → 导出节点​
通过上传模型与材质参考图，对已有三维模型进行材质重新生成。帮助用户快速创建符合需求的材质版本。​
模型输入节点 + 材质输入节点 → Aholo Lux3D 节点 → 预览节点 → 导出节点​
多格式导出​
支持将已有三维模型转换并导出为不同格式文件。上传模型后，选择目标导出格式即可完成模型转换，满足不同三维软件、渲染工具及应用场景下的使用需求。​
模型输入节点 → 多格式导出节点​

@manycore/aholo-splat-transform 是 Aholo Viewer 配套的 3DGS 处理工具,用于格式转换、数据简化、LOD 生成与体素碰撞体生成。​

Chunk LOD​
大规模 3DGS 场景超出单设备能力,Aholo 采用 chunked LOD(stream + LOD)方案:视觉焦点附近保留画质,次要区域牺牲细节,降低资源需求。LOD 数据由后处理 Gaussian 融合生成,无需重训。​
生成流程​
Chunk 切分:八叉树切分,默认每 chunk 最大 400000 Gaussians;大场景可调到 800000+。​
搜索与融合:每级从上一级生成,迭代到目标 count;低保留率层放大剩余 Gaussian 减少空洞;融合后做 opacity culling;每级有最大迭代数防死循环。​
输出:低层(约 1%)打包,生成 lod-meta.json。​
lod-meta.json 关键字段​
TypeScript
interface LodMeta {​
magicCode: 2500660; type: 'lod-splat'; version: string;​
counts: number;          // level 0 总数​
shDegree: number; levels: number; files: string[];​
forwardBox: IBox;        // 约 80% Gaussian 包围盒​
permanentFiles: number[]; // 常驻内存/显存文件​
tree: Array<{​
bound: IBox;​
lods: Array<{ file: number; offset: number; count: number }>;​
}>;​
3.6 常见问题与报错​
3.6.1 Aholo Reality​
Aholo Reality 是否支持 OSV 全景相机格式？​
目前可将OSV格式文件转为MP4格式，上传至 Aholo Reality 完成重建；原生OSV格式支持即将上线。​
Aholo Reality 是否具备尺寸约束功能，可通过局部实际尺寸校准整体模型尺寸？​
支持精准尺寸校准，操作方法：点击工具栏标尺功能，绘制尺寸线段后，按下 CTRL/COMMAND + 鼠标左键点击数值，即可手动修改实际尺寸，完成整体模型尺寸约束校准。​
编辑界面已设置默认视角，为什么分享链接无法固定对应视角？​
模型后端会进行 LOD 层级优化及多项后处理，处理后的数据量远大于原始数据，导致视角同步存在延迟，暂时无法通过默认视角设置固定分享链接视角。​
中心模式和环绕模式的区别是什么？分别适用于什么场景？​
两种模式针对高斯渲染不同层级展示，适配不同编辑需求：​
中心模式：展示高斯点核心数据，适合整体选区编辑，可快速框选整片高斯点批量删除、调整，多用于模型主体结构修整；​
环绕模式：展示高斯环表面数据，聚焦模型表层细节，适合精准选中模型表面的高斯雾、表层瑕疵等细节区域，针对性清理优化。​
Insta 360 X6 拍摄室内全景视频初始坐标点存在问题（如初始坐标点在点云边缘，需要手动漫游才能找到重建好的空间或物体）​
目前用Insta 360 X6拍摄后可能存在初始坐标点偏移的问题，需要用户自行手动漫游至正确坐标点再点击将当前视角设为默认进行修复。​
Aholo AI Generation 是否支持多图导入参考生成3DGS模型？​
支持非真实环境重建的多图参考生成需求，目前多端支持多图导入生成 3DGS 模型。​
3.6.2 Aholo SpatialGen​
Aholo SpatialGen 是什么产品？​
Aholo SpatialGen 是一款专注于 3D 动态可交互世界模型/场景生成与创作 的平台。用户可以通过图 / 文字描述（Prompt）、素材资产导入，快速生成包含 3D 模型（Actor）的可交互物体的 3D世界。​
使用 Aholo SpatialGen 需要什么配置？​
作为一个在线 Web 端/云端创作平台，只要使用支持 WebGL / WebGPU 的主流浏览器（推荐 Google Chrome 或 Edge 最新版）即可体验。云端服务器会自动处理高强度的 3D 渲染与模型生成任务。​
任务队列提示“生成中/排队中”需要等待多久？​
模型生成在15s~1mins / 全景图生成在30s~5mins左右 / 高斯场景生成在15mins及以上；生成速度取决于当前时间段云端计算资源及当前任务数；生成成功后会在底部“任务队列”显示状态（如：创建或编辑 3D Actor 已完成），并在画布中实时更新渲染。​
如何在列表中查找和管理场景内的物体（Actor）？​
画布左下角点击 「显示资源面板」，里面罗列了当前场景中的所有物体资产（如：海星、金枪鱼、海龟、木质宝箱等）。​
选择模型： 在列表中点击对应项目，画面主视角的模型会被选中并呈现高亮外框。​
隐藏/显示： 点击模型旁边的 眼睛图标 可以切换物体的显隐状态。​
定位定位： 点击 定位图标 可快速将镜头对准该物体。​
如何删除场景中不需要的 3D 模型？​
点击对应目标物体，直接Delete / Backspace 进行删除；或资源面板进行操作​
在左侧 Actor 列表 中找到需要删除的模型（例如：金枪鱼）。​
将鼠标悬停在对应行，或点击列表行右侧的「垃圾桶」。​
如何将创作好的资产导出？​
确保「世界」完成生成，进入高斯场景，右上角顶部栏点击 「下载」按钮，即可导出所有资产至本地。​
如何分享给其他人在线体验/协同查看？​
登录 https://www.aholo3d.cn，进入Aholo SpatialGen，找到「我的世界」，选择「项目」点击「分享 」(Share) 按钮，生成公开查看链接。受邀者无需安装软件，直接在手机或电脑浏览器中打开即可进行 360° 交互预览。​
任务队列一直卡在处理中 (Processing）状态不动怎么办？​
尝试刷新浏览器页面（Ctrl + R 或 Cmd + R），系统会在云端保留您的最新草稿，刷新后数据会自动同步更新。​
智能提取无法识别复杂/大型场景中的单个物体怎么办？​
当场景较为复杂、物体彼此重叠时，直接使用智能提取可能无法精准识别。​
解决方法： 点击「自动分割」功能，支持对多个目标区域进行局部框选识别。​

1、遇到生成失败的问题怎么办？类似如下问题（敏感内容/版权违规/生成超时）​
AIGC 生成失败或审核拦截，90% 以上集中在合规风险、内容质量、系统限制三大类，其中 Seedance 模型对「负面情绪、真人肖像、版权 IP」的审核阈值显著高于其他模型：​
版权 / 侵权疑似风险：系统并非判定你一定侵权，而是内容存在合规隐患，这是 Seedance 最常见的拦截原因​
真人肖像权限制：平台禁止使用真实人脸素材生成内容，避免法律纠纷​
提示词内容不适宜：包含负面情绪、暴力冲突、低俗擦边等不符合安全规范的描述​
第一优先级：标准重试（解决 30% 偶发异常）​
绝大多数隐性故障是单次、偶发的，尝试增加空格或者回车，无需修改任何内容，重试即可​
第二优先级：隐性合规深度排查（解决 60% 核心问题）​
按以下清单逐项排查，90% 的 "未知失败" 都能找到原因：​
✅ 快速验证方法：将修改后的提示词发给豆包，使用以下话术进行预审核：​

5.5 常见问题​
说明与处理建议​
没有专业扫描设备，可以使用吗？​
可以使用手机拍摄照片或视频。建议选择光线稳定的环境，保持画面清晰，并从多个角度完整覆盖目标。详见拍摄指南。​
重建结果出现缺失、模糊或异常，怎么办？​
先检查素材是否存在模糊、视角覆盖不足、动态物体或明显反光等问题，必要时补拍并重新重建。多余区域可通过裁切清理；对象分割范围不准确时，可使用局部修正；编辑后露出的背景空缺，可根据补洞提示处理。​
为什么分割工具不可用？​
部分分割功能对方案来源、创建时间和编辑状态有要求。建议先完成分割及范围修正，再进行移动、删除、补洞等后续编辑。具体条件见手动分割教程。​
如何让团队成员查看或复用我的场景？​
将方案投稿至企业方案库，同一企业组织内的成员即可查看和复制；仅需展示时，可生成分享链接。详见企业方案库管理。​
导出的模型能否用于外部引擎？​
支持导出 PLY／SPZ 高斯点云文件，目标工具需支持对应格式与渲染方式。建议先用小规模模型验证效果，再接入完整场景。详见分享与导出。​
